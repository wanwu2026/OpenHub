# OpenHub · General-Purpose Backend Platform

> 🤖 This project was generated by AI.

[中文](README.md) | [English](README_EN.md)

A backend platform you can **deploy to a server in one command**: a web admin UI, APK/artifact management, and pluggable business modules — providing standardized backend services for the existing CardKey client and future SDKs.

**Core design**: kernel + plugins. Write the kernel once (auth, devices, config delivery, artifact hosting, audit, plugin engine). Adding a client = adding a plugin; the kernel never changes.


## One-command deployment

```bash
# Docker mode (server needs docker)
sudo bash deploy/install.sh --mode docker --dir /opt/openhub

# Bare-metal mode (no docker, Python 3.10+)
sudo bash deploy/install.sh --mode bare --dir /opt/openhub
```

The script detects the environment → generates the admin token and initial API key (`.env`, mode 600) → starts the service. Private keys, database, and uploaded artifacts live under `data/`, excluded by `.gitignore` — they never enter the repo or image layers.

## Local development (install dependencies yourself)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8080
python -m pytest tests/ -v
```

## Adding a client (the whole point)

1. Create `plugins/<name>/` with a `plugin.py` defining a `Plugin` subclass.
2. Implement `name`, `routes()`, `health()`, `on_enable()` / `on_disable()`.
3. Add `<name>` to `OPENHUB_ENABLED_PLUGINS`. The kernel is untouched.
